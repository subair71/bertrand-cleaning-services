# Bertrand Cleaning Services

Independent adaptation of Al Maher dev commit 346900392e424c28eda87d326a8b039d85792077. French default / English, LTR, blue-green theme, decorative Eiffel Tower photo and WhatsApp +33605597685. Original project remains untouched.

Run `npm run serve`, then open http://localhost:8080. Build HTML with `npm run build`; run unit checks with `npm test`. No framework or backend required.

All original six services and demo features retained. Public content, forms, errors and admin screens are translated. Requests, uploads and dashboard edits are simulated in tab memory; never production submissions.

Exact address, service area, hours and official Bertrand logo are pending. The typographic wordmark is provisional. Offers carried over from the source require Bertrand approval. Production requires backend, secure authentication, storage, spam protection, approved legal documents and hosting/domain selection. Canonical URLs, hreflang and sitemap must use the approved production origin. See docs/PRODUCTION.md and docs/proposal.html.

GitHub repository: https://github.com/subair71/bertrand-cleaning-services — working branch `dev`, retaining the source history.
